# Portfolio d'Ingénierie — Moustapha Ibrahim Djama

Portfolio professionnel et technique d'élève-ingénieur en Génie Électrique, Énergie & Data (ECAM-EPMI). Recherche de stage de fin d'études de 6 mois à partir de février 2027.

---

## 🚀 Déploiement en 1 clic sur Vercel

Ce projet est 100% prêt pour Vercel (configuration incluse dans `vercel.json`).

### Méthode 1 : Déploiement via GitHub (Recommandé)
1. Créez un nouveau dépôt sur [GitHub](https://github.com) (ex: `portfolio-moustapha`).
2. Déposez les fichiers de ce projet dans votre dépôt.
3. Rendez-vous sur votre compte Vercel : [https://vercel.com/moustaleddistallo-8831](https://vercel.com/moustaleddistallo-8831)
4. Cliquez sur **"Add New..."** > **"Project"**.
5. Sélectionnez votre dépôt GitHub `portfolio-moustapha`.
6. Laissez les paramètres par défaut (Framework: **Vite**, Build Command: `npm run build`, Output Directory: `dist`).
7. Cliquez sur **"Deploy"** ! Votre site sera en ligne en moins de 60 secondes avec une adresse HTTPS sécurisée.

### Méthode 2 : Déploiement direct avec Vercel CLI
Dans le dossier du projet :
```bash
# Installer Vercel CLI globalement si ce n'est pas déjà fait
npm install -g vercel

# Se connecter à votre compte Vercel
vercel login

# Lancer le déploiement en production
vercel --prod
```

## 💻 Lancer le projet en local

1. **Installer les dépendances** :
   ```bash
   npm install
   ```

2. **Démarrer le serveur de développement** :
   ```bash
   npm run dev
   ```
   Le site sera accessible sur `http://localhost:3000`.

3. **Compiler pour la production** :
   ```bash
   npm run build
   ```
   Les fichiers optimisés seront générés dans le dossier `dist/`.

## 🛠️ Stack Technique
- **Framework** : React 19 + TypeScript + Vite
- **Styling** : Tailwind CSS v4
- **Icones** : Lucide React
- **Animations** : Framer Motion
- **Images** : Photos réelles d'installations électriques, schémas de câblage et plans unifilaires
